Waymaker Server Backup is a private utility operated by Waymaker for the authorized account owner's server backups. It is not a public backup service or a sign-up service for other users.

서버 운영자가 지정한 데이터를 암호화해 본인의 Google Drive에 보관하고, 필요한 경우 복원하는 도구입니다.

What it does

  • Encrypts selected server data and configuration locally with restic before uploading it.
  • Stores and verifies encrypted backup objects in the operator's designated Google Drive repository folder.
  • Reads existing backups for integrity checks and recovery, and manages retention when the operator requests it.

Why it requests Google Drive access

The utility uses the Google Drive API through rclone to maintain an existing backup repository, including files created before this OAuth client was registered. It requests the full Drive scope, https://www.googleapis.com/auth/drive.

This Google permission is broader than a single folder: it can authorize reading, creating, changing, and deleting files in the connected Drive account. The utility is operationally configured to use the designated backup repository and the account or folder metadata needed to locate and maintain it. That configured folder limit is not a folder-level restriction enforced by the OAuth scope.

Authorization and control

Only the account owner authorizes access through Google's consent flow. This website does not ask for Google passwords or OAuth tokens. The operator can revoke the connection in Google Account connections. Revocation stops future authorized access; it does not delete backups already stored in Drive.
