Waymaker Server Backup is a private utility for the authorized account owner. It encrypts selected data before saving it to the owner’s Google Drive, where backups can be verified and restored.

계정 소유자가 지정한 데이터를 암호화해 본인의 Google Drive에 백업하고, 필요할 때 복원하는 개인용 도구입니다.

Google Drive access

The app requests full Google Drive access to manage backups in an existing backup location, including files created before this app was authorized. This permission can read, create, change, and delete Drive files and is not limited by Google to one folder. The app uses it for the designated backups and the account and folder information needed to manage them.
