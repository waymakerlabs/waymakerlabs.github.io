Effective November 5, 2026 · Updated November 9, 2026

This policy applies to Waymaker Server Backup, a private backup utility for the authorized account owner.

Data and permissions

The app uses encrypted backup files and the account, file, and folder metadata needed to locate, store, verify, restore, and manage those backups. It requests full Google Drive access (https://www.googleapis.com/auth/drive) to work with an existing backup location, including files created before the app was authorized. Google grants access beyond that location; the app uses it only for the backup purposes described here.

Storage and sharing

Backup contents are encrypted before upload and stored in the owner’s Google Drive. Google authorization credentials are stored securely. The operator may access data to perform authorized backup, recovery, or support. Google user data is not sold, used for advertising, used to train general AI models, or shared with unrelated parties. The app’s use and transfer of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Backups are kept according to the operator’s retention settings and can be deleted by the owner. The owner can revoke access in Google Account connections. Revocation stops future access; it does not delete existing backups. For access, deletion, or privacy questions, contact waymakerlabs@gmail.com.
